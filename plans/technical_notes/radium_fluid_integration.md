# radium 公共流体接口接入

2026-11-06。实现入口为 `server/adapters/compat/fluids.py`，装配与设备接线在
`server/bootstrap.py`、`server/devices/bus_io.py`。

## 前置与接入范围

本地 `.mcdev.json` 的 `included_mod_dirs` 加入 `D:\addon\transferlib`。
该配置受 Git 忽略；其他开发环境及发布包需安装 radium 行为包、资源包。
遵循公共 API 约定，不导入 radium 或 SkyBlueTech 私有脚本、不添加强制 manifest 依赖。
每次业务访问通过 `GetComponent(levelId, "radium", "transfer")` 发现服务，
要求主版本 1 且版本至少 1.1.0。缺失或不兼容时返回无适配器，之后重新发现。

- 主动流体存货口从朝向机器抽取，取货口向朝向机器注入。
- 样板接口按批次的资源类型选择物品或公共流体端口，仍按既有六面顺序投料。
- 被动流体接口尚未定义本地储罐容量和槽位表示，继续明确返回 `no_adapter`。
- 不改变能源、带宽、投料量、过滤规则或订单回流归属；不新增 RF 到 EN 换算。

## 端口与身份契约

查询 `api.query(api.FLUID, dimension, pos, face)`，传入目标机器的原生绝对面。
接口朝上/下/北/南/西/东分别访问目标 0/1/3/2/5/4 面。
稀疏槽位遍历 `get_slots()`，读写权限由机器提供者决定。
输入槽虽然可能可见，但会通过放弃事务的按槽抽取模拟从供应候选中排除，
避免首个只入槽阻塞后面的可出槽。

完整公共身份映射为 `ResourceKey.fluid(id, user_data=properties or None)`。
写入前用公共 API 反向构造身份并核对往返相等；拒绝无法无损表示的键，
例如 EnderNet 中区别于缺失属性的空字典。名称相似的资源不合并，
同 ID 不同属性不混合，整数/浮点/布尔属性的类型差异保留。

## 数量、模拟与提交

EnderNet 保持整数 mB 记账。公共端口每次返回实际接受或提取的浮点 mB：

1. 打开根事务，调用公共 `insert` / `extract`。
2. 返回有限、非负、不超过请求量的整数时才允许提交。
3. 返回小数时放弃整次事务，以其向下取整值重试一次；重试仍返回小数则放弃。
4. 模拟路径从不提交；不足 1 mB 的余量留在外部机器。

供应枚举按槽取可抽出的整数量，因此多个不足 1 mB 的槽不会自动合并搬运。
每次请求及无限源供应提示上限为 `2**53-1`，真实调度仍受既有搬运预算限制。
创造源、虚空接收端按公共事务的实际回执记账，不用前后储量差否定合法转移。
已知 `TransactionError` 表示未提交；未知提交异常返回 `uncertain`，
交给原有中转与恢复机制，禁止自动重放。外部事务与 EnderNet 网络转移仍分开，
不声称跨存储全局原子或跨方块存档崩溃原子。

## 生命周期

提供者只缓存坐标和面，所有读取、模拟和提交重新查询公共端口，不缓存 query 代理。
方块/邻居变化、区块加载卸载、停止与重新扫描会作废相关地址缓存。
缺少通知时使用既有接口轮询及退避；缺少组件不会永久缓存失败。
