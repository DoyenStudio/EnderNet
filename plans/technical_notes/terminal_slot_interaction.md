# 终端槽位交互与持物归属（R12）

适用于通用、合成和样板终端。工厂终端展示订单，订单行打开详情，用料图标只读。客户端按当前输入模式选择键鼠或触控，切换输入模式会撤销拖拽；从键鼠切回触控时由服务端归还持物。

| 区域 | PC 键鼠 | Pocket 触控 |
| --- | --- | --- |
| 网络物品 | 左键取至多一组；右键取可取一组的上半数（向上取整）。手中有物品时左键存整叠、右键存一个。Shift 左键快移一组进背包，Shift 右键向光标补一个。Shift 滚轮向上存一个、向下取一个。空手按住一行同样是长按拿取（至多一组）。 | 点来源再点目标。背包选中后也可点网络空白处快捷存入。长按可合成条目进入数量选择。按住网络行拖到背包格取一组。 |
| 背包和快捷栏 | 左键取放、合并、交换，右键取半、放一。双击一叠物品可补满光标上的这一叠。左拖均分，右拖逐格放一。Shift 点击存入网络，Shift 双击处理同区同种物品。空格点击批量转移当前区域。空手按住一格：按下即拿起整叠，按够 0.4 秒物品回到格子、光标上方出现原版旧式灰底绿色进度条，数量随时间从 1 涨到整叠（1 秒涨满），松手把这么多拿到光标上（`slot_click` 的 `take`）。空手时鼠标下按 Q 丢出一个、Ctrl+Q 丢出整组（先 `take` 到光标再 `cursor_drop`，与点窗外丢出同一条命令；没丢成就把光标还回背包）。 | 点来源再点目标，支持移入空格、交换和合并。连续短点同一叠物品两次可补满该槽。长按背包格渐进拆堆：过 0.4 秒门槛后格子上方出现大数字进度条，默认一半（向上取整），右滑加、左滑减，滑过进度条宽度（64 像素）为整叠、最少 1 个；松手后大进度条消失，以该数量选中这一格，格子上显示原版灰底绿色小进度条（拆出数量 / 整叠），直到取消选中或放下；再点目标格只放这些（只能放进空格或同类格，合成格只收整格）。没到门槛就挪动为拖动：按住背包格拖到别处松手直接放下（背包格合并、移动或交换，网络区存入，合成格整格放入，拖出窗口为取消）。

| 合成输出 | 左键做一次到手，右键至多做一组到手，Shift 点击至多做一组入背包，空格点击按背包容量批量执行。每次等上次回执和九宫格修订同步，材料或空间不足即停止。 | 短按做一次，长按输入合成次数。 |
| 样板 | 原料及可编辑产物格复制配置。持物左键配置整叠，右键配置一个；空手左键清除、右键减一，中键改量。按当前样板模式锁格。样板输入与成品走实物槽规则。 | 保留两点复制、清空与长按改量或选配方。 |
| 自动合成 | 中键点击可合成条目，或空手左键点击零库存可合成条目，进入数量窗和订单预览。 | 长按可合成条目，后续预览和确认流程相同。 |

键鼠的右键与 Shift 点击按格子分名（`<前缀>_secondary`、`<前缀>_quick`，见 `terminal_panel.SLOT_REGIONS`），回调直接取 `#collection_index`；只有拖动过的那次抬起才按鼠标位置命中松手处。双击按两次点击的间隔判定（0.25 秒）；2026-11-08 试过 `double_pressed` 映射，实机双击不触发，已删除。

双击补堆先从背包和快捷栏收集完整物品身份相同的物品，再从网络提取可用库存，最多补到该物品的一组上限。网络取物受预留和当次传输额度限制，供给不足时收集实际可取的部分。

键鼠持物划过多个背包格、快捷栏格或合成原料格时，界面随划入的格子重算。左拖按有效格数平分手中物品，右拖每格放一个。格内已有的同种物品占用该格容量，余数留在光标上。样板的可编辑虚格显示要复制的配置数量，实物均分时只计实物槽。松手时将最后一次分配合成一条 `slot_batch` 请求，服务端核对后按顺序落账，统一回执。拖拽松手及收到批量回执时均不播放 flying_item 动画；预览保留至回执及设备快照同步完成，失败或部分完成时撤销预览并显示真实状态。

### 协议与退出

- `slot_batch` 沿用 `TerminalCommand` 信封，`config` 为 `{revision, placements}`。每项为 `{target, cell, count, slot_version}`，背包项另带 `fingerprint`；背包 `cell` 使用引擎槽号，设备格使用各区域格号。支持 `bag`、`grid`、`source`、`outputs`，每批 1～64 项，目标不得重复，数量必须为正整数。普通单槽操作继续使用 `slot_click`。
- 批量命令先校验整批结构、起始持物版本及所有目标槽／设备版本；校验失败不执行任何放置。执行期间由服务端推进持物及设备版本，样板虚格复制批次开始时的持物身份，不消耗实物。容量不足、槽位拒绝或写入待核对时停止后续项，保留已完成操作，不承诺整批回滚。统一回执包含已尝试项的实际数量、最终持物、背包槽读回及设备修订号；已有完成项则返回 `partial`，客户端不自动重发。外层请求沿用既有会话和请求去重机制。

- 背包快照保留引擎槽序，可附加持物的资源键、数量及修订号。服务端按会话取得玩家和设备。PC 的 `slot_click` 校验持物修订、背包槽指纹及修订或设备修订。Pocket 的 `grid_move` 校验真实来源和目标。显示行仅在客户端使用，网络请求携带完整资源键。
- 自定义面板使用玩家 ExtraData 保存唯一持物栈。存档值是 JSON 文本，以保留特殊物品字段并兼容网易引擎的 Python 2 字符串要求。旧世界从空持物开始。
- 触屏选中背包格时点窗口外：先用 `take` 把选中的数量（长按拆出的就只是那些）拿到光标上，再排队 `cursor_drop` 抛出；拿到了却没丢成就发 `cursor_return` 还回背包（触屏看不见光标）。网络行的选中不丢。窗口外的判定取回调坐标，取不到时用跟手宿主的位置。
- 键鼠持物时点窗口外：左键丢整叠、右键丢一个（原版 `cursor_drop_all` / `cursor_drop_one`）。三台有持物的终端在 `main` 的屏幕层映射 `#EnderNetTerminal.drop_cursor_all/one`，客户端再核对鼠标在窗口矩形外，排在其它格子请求之后发 `cursor_drop`（`config` 为 `{revision, count: "all"|"one"}`）。服务端核对持物修订后照原版按 Q 抛出：`CreateEngineItemEntity` 在眼高往下 0.3 格生成，再 `SetMotion` 沿视线 0.3 格/刻、向上 0.1 并加小随机（数值按 Java 版推断）；拿不到实体 id 按没生成算（同 `drop_items_at`），速度设不上不改判。与关屏掉落共用同一份掉落日志。
- 正常关屏先合堆、再找空位，装不下的余量掉在玩家位置。离线持物等重连后归还。死亡按世界的保留物品栏规则掉落或留到复活归还。
- 直接交换或取放两个实物槽时先记录操作前后状态。实际落点的完整物品身份和数量与预期一致后结清持物。仅当引擎明确拒绝此次写入且槽位仍是原状时，才可取消这笔交易并重试。回执缺失、写入中断或旧记录只读到原状时保留待核对，以防同一件物品发放两次。打开面板及后续背包同步会核对待归还的原背包槽，已到账的物品直接结清。掉落实体生成结果未知时也保留待核对。
- 单槽飞行动画以命令回执为准，拖拽批量放置不播放。合并和交换以实际槽位为端点，编码与样板复制使用独立的视觉反馈。网络行按资源键定位，动画控件池复用多个预制渲染器。

### 界面维护

PC 鼠标悬停网络列表、背包／快捷栏、合成或样板槽时高亮该格并显示物品 hover 信息，不追加数量行。仅网络列表中有生产样板（`has_pattern`）的物品追加 `§e[可制造]`，与当前库存数量无关；背包及设备槽不追加该标记。移出物品、打开模态窗、会话失效或切换触屏时收起。沿用 MoreEnoughItems 普通物品提示的 `common.hover_text` 原版渲染器与 `GetItemFormattedHoverText` 接口；传入物品 aux 和已有 userData，保留引擎格式和自定义说明。合成／样板槽当前同步协议只提供 name、aux 和数量，因此只显示这些数据可还原的提示，不解析 canonical 指纹。触屏保留原有选中物品的底部说明。

高亮与提示都是格子按钮的悬停态（`endernet_windows.item_can_be_selected` 的 `hover`）：原版 `common.highlight_slot` 位于物品图标之下，`common.hover_text` 绑定本格的 `<前缀>_hover_text`，条件为 `always_when_visible`，因此只有被悬停的那一格回调 Python，不再轮询命中。hover 文本按物品身份缓存，可制造标记随行状态拼接。拖拽及等待分配结果期间、模态窗打开或触屏时该绑定返回空串。终端底部的文字已删除，改为原版 `selected_item_details` 样式的气泡（`endernet_ui_common.item_details`，铺满屏幕的根面板底部居中、上移 16 像素，紫色边框）：触屏选中物品时显示与键鼠悬停相同的提示文本，回执失败的原因两种输入都显示；每次出现从不透明开始，2 秒内 in_quint 淡出。

触屏手势在 `touch_input.TouchGesture`：拖动只看按下与松手两处，位置取按钮回调参数里的 `TouchPosX/Y`，拖出按钮后松手由 `BF_ButtonClickCancel` 接住；按住期间读跟随光标的 `cursor_host` 位置，只用来判断挪动、计算滑动量并摆放跟手图标。`cursor_host` 两种输入都常开（隐藏时不跟手，触屏第一次长按会停在左上角）。大数字进度条（`split_overlay`，原版 `inventory_hold_icon_holding` 的图片与文字）挂在铺满屏幕的根面板上，按格子位置摆放，上方放不下时改放下方。三条 `progress_bar_renderer` 进度条直接继承原版控件，数据照原版走绑定：选中格小进度条 `split_bar@common.inventory_hold_icon_release`（挂在三台终端窗口里，与 `cursor_host` 同级）、键鼠长按拿取 `cursor_host/cursor_take_bar@common.inventory_hold_icon`（光标上方 12 像素）、持物耐久 `cursor_host/cursor_durability`；`endernet_container_common` 把 `#EnderNetTerminal.<名字>_visible/_total/_current` 覆盖到 `#touch_progress_bar_visible`（或 `#progress_bar_visible`）与 `#progress_bar_*_amount`，由 `terminal_panel.PROGRESS_BARS` 的绑定供数。2026-11-08 先用属性袋（`SetPropertyBag`）写数，实机灰底绿色条不显示，已改为绑定。暂用原版贴图与尺寸，待 User 改样式。2026-11-08 起长按背包格不再存半叠（10-01 的约定由 User 改定），客户端 `on_backpack_split` 已删除，服务端 `inv_split` 保留。

全部界面的 `main` 用原版容器的暗底（`common.screen_background`，alpha 0.4）。`root_screen_panel` 是铺满屏幕的 `endernet_ui_common.screen_root`，各界面的内容区由 `$window_content` 以 `window` 挂在它下面，大小不变；脚本经 `slot_layout` 解析路径（`WINDOW_ROOT`），不手拼。悬停高亮用白色半透明（`textures/ui/White`，alpha 0.4），原版 `highlight_slot` 贴图是绿色。格内数量照原版 `common.stack_count_label`（默认字号，偏移 [0,1]）；格子 18、图标 16 与原版经典 UI 一致。

格子的四条数据绑定（可见、图标、选中、数量）每渲染帧自取。2026-11-08 试过改为按需刷新，界面刷新落到 tick 频率，操作明显不跟手，已改回。格内另有原版耐久条（`#item_durability_*`，按集合区分），模板把它的三条绑定改为 `always_when_visible`，同样每帧自取，并以 `ignored: false` 取代原版对祖先变量 `$durability_bar_required` 的依赖。2026-11-08 曾用帧末签名 + `UpdateScreen(True)` 刷新耐久条，实机操作有滞后、飞行动画像是重播，已删除。回执到达后 0.5 秒内背包按帧重读引擎（平时每 12 帧一次），格子不必等下一次轮询。持物图标照原版 `inventory_selected_icon`：21×21、中心相对鼠标偏 (-1, -2)，数量贴 16 格右下角，被拿起的受损工具显示耐久条。

宿主 JSON 预制其需要的数量、选择、名单、配方候选、设备状态、订单与设置窗口。窗口控制器按实例名定位、显隐和清理模型；配方候选按 collection 绑定，超过一屏时滚动。通用导入器在自有面板上查找预制覆盖层，第三方宿主在打开采集器时挂载覆盖层。采样命中框随目标界面上可见物品的位置生成。
