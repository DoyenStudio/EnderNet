# 谐振燃料发电机直接供给 EN · 2026-11-15

发电机作为网络节点接基带、光缆和其他设备，DOS 与小型控制器均支持；零耗能、零带宽，发电和入网不依赖网络已有能源。产能为 64 EN/t，煤炭／木炭每份燃烧 1600 tick，共 102400 EN，缓存 32000 EN；不再注册 FE 端口。加工机继续接收外部 FE。

## 游戏验证

通过项目 MCDK 会话完整重载资源与游戏。在已确认全部为空气的区域临时放置 DOS、8 位基带、普通光缆、发电机与通用终端，使用引擎方块容器和原生 block entity tick；未直接调用机器 `tick()`。原始读数见[验证数据](generator_network_2026-11-15.json)。

| 场景 | 结果 |
| --- | --- |
| 无燃料、空缓存 | 网络 `no_power`、需求 8 EN/t；发电机 `waiting_fuel`，仍为在线 |
| 插入一份煤 | 244 个原生机器 tick 后燃烧剩余 1356 tick、缓存 13696 EN，煤槽为空；网络恢复 `runnable`，结算 8 EN/t |
| FE 端口 | `radium:energy` 查询发电机返回空 |
| 缓存接近满 | `buffer_full`；单次完整发电量放不下时暂停燃烧 |
| 原生数据重载 | 卸载／重新加载机器适配器后，缓存 31960 EN 与剩余燃烧 774 tick 完全一致 |
| 客户端单位 | 实际客户端格式化 32000 为 `32.00 kEN`；加工机仍为 `32.00 kFE`，MEI 单位有离线回归 |
| 清理与错误 | 五个临时方块全部还原空气，源节点撤销；服务端 tick errors 与新增引擎错误日志均为空 |
