## 1. 入口与复用要求

`CommonTerminalPanel`、`CraftingPanel`、`TemplatePanel` 同继承 `TerminalPanelBase`，共用 `TerminalListView`、`TerminalCache` 和背包模型。网络标记、长按和预览应在共享组件落地，三种终端调用同一逻辑；不要在两种子面板各复制一份。样板终端 `config` 的短按协作仍有效，但已识别的下单长按必须吞掉随后短按。

工厂终端目前没有同样的网络仓储区，本任务不新增该区域；其订单查看／取消与预览“取消”必须区分。既有工作台合成、样板编写不属于本任务重写范围。

## 2. 分层实现表

代码根为 `endernet_bp/endernet_scripts/endernet/`，下表路径相对该根；UI 路径相对仓库根。文件名为定位点，新文件名属于建议。

| 层／位置 | 待实现内容 | 完成判据 |
| --- | --- | --- |
| `server/crafting/store.py` | 复用产物索引；提供符合契约的样板产物集合与变化通知／版本依据。区分注册存在与当前可用；`output_keys()` 的诊断口径不能无检查当交易资格 | 新增、修改、过时、移除及提供者变化能准确刷新；同产物多样板不会误删 |
| `server/storage/service.py` 与新增网络显示投影 | 合并真实库存和样板产物，按 ResourceKey 生成 stored/reserved/has_pattern；库存保持权威语义，显示投影维护自己的变化与版本 | 不写假库存；库存取空后正确保留 `+` 行；纯样板变化可发布 |
| `common/protocol.py` | 扩展显示摘要与新增预览请求／状态／结果／确认提交契约；所有编解码、资源引用、严格字段校验同步调整；保留交易库存版本语义 | 快照和增量无字段漂移；资源描述与引用模式均往返正确；数量仍为整数 |
| `server/sync/terminal.py`、`server/sync/transfer.py`、必要时 `sessions.py` | 从显示投影发布网络摘要；预览身份、结果分批、取消清理、会话与版本检查；不可仅靠存储 dirty_items 驱动 | 断线重同步能恢复；旧预览／旧会话包不覆盖新结果；纯样板网络变化也生效 |
| `server/bootstrap.py`、`server/application.py` | 按所属网络注入样板和显示投影；接入服务端预览调度及正式提交入口，保持权限／主控准入路径 | 无旁路交易或执行资源占用；所有入口能由真实终端会话到达 |
| `server/crafting/planner.py` | 复用 PlanJob、InventorySnapshot、PatternSnapshot、材料账本及候选规则；补足实际依赖归属、每步需求、汇总及自底向上缺料传播 | 深层缺料上行标记；库存不重复分配；每 tick 节点及搜索预算符合 08；大汇总不会完成帧卡顿 |
| `server/crafting/execution.py`、`jobs.py` | 把预览请求与正式订单提交分开；确认时重校验／按策略分帧重算，衔接原订单准入和拒绝记录；幂等提交 | 预览无租约／预留／执行订单；正式订单只创建一次；过期预览不获准 |
| `client/network_client.py` | 收发预览消息、结果批次与查询代次，取消／提交回执、会话清理 | 陈旧、乱序、不完整结果不得开启提交 |
| `client/ui/item_list_model.py`、`terminal_cache.py` | 承载样板标记、零库存显示行、变更合并与排序／筛选／选中 | 无样板零库存才移除；排序切换和增量不把选中目标改成其他资源 |
| `client/ui/terminal_panel.py` | 共用 `stored+`／`+` 数量标签；网络槽按下／释放长按状态，捕获资源键，吞短按；调用 show_number_set_window 并确认后开预览 | 三种终端同一行为；无 `+` 长按不下单；无库存不发送取物命令 |
| 建议 `client/ui/order_preview_window.py` | 公共预览窗口控制器：loading、完整结果、行颜色、按钮禁用、提交／取消、重开／销毁清理 | 不叠窗，不漏回调；下单只发生在确认按钮；异步错误可恢复 |
| `client/ui/crafting_panel.py`、`template_panel.py`、`ui/__init__.py` | 只补共享控制器生命周期／注册，核对样板虚格优先级、合成选择列表和退出清理 | 不重复实现共享逻辑；原短按和设备专属槽位不回归 |
| `endernet_rp/ui/common_terminal_panel.json`、`crafting_terminal_panel.json`、`template_terminal_panel.json` | 在三种网络槽模板接同一长按事件；保留字符串数量标签和现有共享绑定 | 真正有按下／释放映射；长按不会透到背包搬运或样板清空 |
| `endernet_rp/ui/endernet_windows.json` | 接预览 collection 行数／图标／数量／颜色、loading visible、下单 enabled、取消／关闭事件；保留已有窗口结构，清理测试初值 | 现有 11 行／2×2 静态网格值改为真实动态数据；结果变更后无红色残留 |
| `endernet_rp/texts/`（实际本地化位置需核对） | 加入需要的预览状态、错误、数量及阻塞文本 | 不把原料不足、计算失败、预算耗尽混成一个状态 |

3. 接公共窗口与三种终端长按，接 JSON 事件、loading、行颜色和按钮禁用。

## 5. 回归与验收表

| 场景 | 必须观察到的结果 |
| --- | --- |
| 库存 256／1／0 且有样板 | 分别显示 `256+`／`1+`／`+`；纯样板行可被搜索／排序 |
| 库存被全部预留 | 标签仍为 stored+；取物可用量为 0，不凭标签发出取物 |
| 同产物多个样板／移除最后一个／过时／离线／换网 | 标记按注册有效性更新，可用性另由规划检查；同键不重复显示；无库存无样板才删行 |
| 长按／短按／释放／滚动后重排 | 一次长按只开数量窗，释放不搬运；目标资源不漂移；普通短按行为不变 |
| 数量确认／取消／非法数／重复打开 | 确认后开预览，取消无请求；非法值服务端拒绝，不叠窗 |
| 父配方直接缺料／孙级叶子缺料／同键多分支 | 对应需求行及受影响中间品行红色，其他行正常；任何缺料整单禁止提交；账本无库存重复使用 |
| 候选成环但另一路可满足／库存满足中间品 | 成功实际路线不被未采用失败候选染红；遵守库存优先及 08 候选政策 |
| 多次相同配方／大树／同 tick 重入 | 执行次数、需求总量和预算正确；loading 在完整计算与接收完成前保持显示 |
| 计算完成无缺料／超预算或错误 | 前者结束 loading 并允许有效提交；后者不展示可下单的假成功 |
| 预览后材料被他人取走／样板修改／网络改变／内存不足 | 确认提交重新校验并拒绝或按策略重新预览，不接受失效计划 |
| 双击下单／请求重发／关闭后迟到包／断线重开 | 只建一次订单；无旧结果覆盖／无遗留窗口、订阅或预览工作 |
| 三种终端与移动端真机 | 数量文字、长按、窗口层级防穿透、颜色、禁用按钮均真实生效；工作台和样板配置原行为正常 |
