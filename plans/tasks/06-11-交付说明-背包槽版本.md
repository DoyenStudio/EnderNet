# 06 / 11 背包槽版本交付（2026-09-30）

D-06 销账为 S-15，采用原方案 1：玩家端点按玩家缓存，退出时和适配器一起失效，版本校验继续保留。

## 实现

`EngineInventoryProvider.endpoint_of` 不再重建端点；同步和命令共用版本台账。`ServerBootstrap._on_player_leave` 同时关闭终端会话并清理背包端点。

`InventoryEndpoint.inventory_view` 一次读取整个背包。终端同步中枢在有订阅的网络推进时发送 `inventory_snapshot`：`revision` 加 36 个引擎顺序槽的 `slot`、`canonical`、`count`、`slot_version`。内容相同不重发、发送失败重试、读取失败不伪造空背包；关闭会话清理发送缓存。

客户端只接收当前会话／网络／epoch 的快照，丢弃较旧修订，关闭或重开会话清空版本。背包显示仍读本地引擎；存入前匹配服务端同槽指纹，发送真实 `slot_version`。快照未到或指纹不符时等待同步，不再发 None 绕过校验。

## 验证

新增 10 项回归覆盖重复获取端点、观察到的 A→空→A 与 A→B→A、旧请求拒收且新版本可用、玩家与会话隔离、离线旧引用失效及退出回调、快照发送失败重试与不变不重发、读取失败、乱序快照、客户端缺失／不匹配快照、协议坏版本拒绝。既有终端测试已改为断言回传真实服务端版本。

`python -B endernet_tests/run_tests.py`：当前工作区 **2429 项测试通过、79 文件通过 Python 2.7 语法门禁**。总数包含其他已有改动；本次没有修改方块定义或生成资源。未做游戏内验证。

## 边界

版本是服务端观察到的指纹修订，不是引擎事件序号；观察间隔中未被看到的 A→B→A 无法识别，单纯数量变化不增加槽指纹版本。玩家离线后重新计数，旧终端会话不能跨会话沿用。

旧调用方仍可显式传 `SlotAnchor.expected_version=None`，终端按槽存入不再使用。R12 持有物、其他手势、持久恢复与 11-12 游戏验收仍未完成，不整体补勾 11-12。
