# 示例网络结构

## 简易仓储系统

```plaintext
(网络基带)+------------+------------+
         |            |            |
    小型网络控制器  存储驱动器  通用终端面板
```
在存储驱动器中放入**存储介质**后，为网络供能，即可在**通用终端面板**处手动存取物品。


## 简易自动存取仓储系统

```plaintext
(网络基带)+------------+--------------+----------+
         |            |              |          |
    小型网络控制器  存储驱动器    总线物品取货口    | 
                                    熔炉>-->总线物品存货口
```
在**总线物品取货口**设置原料（如粗铁），可以自动将设定原料输送至紧贴它的熔炉；为熔炉提供足够的燃料，用诸如漏斗的传输介质将产物导流回网络中，实现简易的熔炉全自动生产。
