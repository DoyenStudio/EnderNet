# 示例网络结构

## 简易仓储系统

```plaintext
(网络基带)+------------+------------+
         |            |            |
    小型网络控制器  存储驱动器  通用终端面板
```
在存储驱动器中放入**存储介质**后，为网络供能，即可在**通用终端面板**处手动存取物品。


## 简易自动存取仓储系统

```plaintext
(网络基带)+------------+--------------+----------+
         |            |              |          |
    小型网络控制器  存储驱动器    总线物品取货口    | 
                                    熔炉>-->总线物品存货口
```
在**总线物品取货口**设置原料（如粗铁），可以自动将设定原料输送至紧贴它的熔炉；为熔炉提供足够的燃料，用诸如漏斗的传输介质将产物导流回网络中，实现简易的熔炉全自动生产。


## 简易订单系统 - 自动工作台合成（单并行）
```plaintext
(网络基带)+-----+-----+-----+
         |     |     |     |
         C     S     R     F

+-|: 网络基带连接
C:   小型网络控制器   S: 存储驱动器
R:   装配仓          F: 工厂终端面板
```
在**装配仓**放入**合成样板**以指定合成配方；在**工厂终端面板**选择合成样板所存储的配方，网络即可将原料送入对应装配仓、自动将产物储存回网络中。

若网络缺失其中一种原料，而该原料又能由别的样板配方合成，则**在同一个订单内**先展开这条子树的配方任务，产物充足后再继续最终配方——**不另开“子订单”**（口径见 [concepts.md](./concepts.md) 订单·规划与执行规则）。


## 简易三并行订单系统 - 自动工作台合成（单并行）
```plaintext
(网络基带)+-----+-----+-+-+-----+
         |     |     | | |     |
         C     S     R R R     F

+-|: 网络基带连接
C:   小型网络控制器   S: 存储驱动器
R:   装配仓          F: 工厂终端面板
```
